# 联赛模拟真实化方案（League Realism）

> **进度（2026-09-05）：六步全部实现，UI 已上线，烟雾验证通过。全量回归（run_all.py）待游戏内确认后运行。详见文末「实施进度」。**

目标：每年用真实单场模拟跑出全部 18 个联赛的积分榜，升降级、国内杯赛、超级杯、欧冠/欧联/欧协联/亚冠的参赛资格与赛制全部从真实榜与现实规则出发；引入跨联赛绝对强度体系和球队实力起落机制。

已确认的决策：
- 欧战范围：欧冠 + 欧联 + 欧协联；亚冠精英联赛。
- 洲际淘汰赛：两回合主客制（新 `_tieSim`），决赛单场。
- 欧冠/欧联/欧协联 36 队瑞士轮联赛阶段；亚冠 24 队联赛阶段（前 8 直进 16 强，9–24 附加赛）。
- 资格赛：1–2 轮淘汰制，由配置池自动凑数。
- 联赛整季后台结算出榜；可操作的只有既有大场（德比/升级附加赛/保级战/洲赛决赛）与杯赛淘汰赛。
- 无次级联赛的 12 个联赛零降级（球队名单永久不变，联赛活力靠 teamDev）。
- 升降级后 rep 重新归位：升班马在新联赛设为低档（0–1），降班马设为高档（4–5），teamDev 保留。
- 球员个人数据沿用现有统计公式（球队进失球来自真实比赛，个人数据受其上限约束）；球员对球队强度的加成联赛内按份额衰减（初值 = 杯赛份额×0.6、封顶 +12），校准步按现实打磨。
- 不考虑旧存档兼容。

## 一、绝对强度体系（跨联赛）

### 1.1 联赛基准强度 `LEAGUES[].str`（新增字段）

绝对强度刻度与现有 `_matchSim(aStr,bStr)` 兼容（旧假强度为 `50+rep*8`，rep5=90）。`str` 定义为该联赛"中游球队（rep=2）"的强度：

|---|---|---|
| epl | 84 | 英超 |
| liga | 83 | 西甲 |
| bund | 78 | 德甲 |
| seri | 77 | 意甲 |
| l1 | 74 | 法甲 |
| tur | 69 | 土超 |
| pri | 68 | 葡超 |
| ere | 66 | 荷甲 |
| ch | 65 | 英冠 |
| jup | 64 | 比甲 |
| spl | 63 | 沙特 |
| b2 | 62 | 德乙 |
| jl | 61 | J 联赛 |
| seg | 61 | 西乙 |

效果示例：西甲垫底队 = 83−6 = 77；中超冠军 = 54+6+dev ≈ 60–66，踢西甲保级队胜率约 15–25%，符合现实差距。数值在校准步（Step 6）可调。

### 1.2 球队绝对强度

```
_teamAbs(t) = league.str + (t.rep − 2) × 3 + _tDev(t.id)
```
- `t.rep`（0–5）为联赛内档次 → 联赛内 ±6 的自然差距；升降级后 rep 重新归位（见 §三）。
- 球员所在队改用 `_playerStr(lg.str + (t.rep−2)*3, ovr, rank)`，联赛内份额 = 杯赛份额×0.6（封顶 +12），杯赛保持原样；具体系数校准步打磨。

### 1.3 球队实力起落 `teamDev`（存档字段 `a2.teamDev`）

每支球队一个 dev 值（初始 0），每赛季结算一次：

```
delta = 预期名次(含 dev 的自洽强度排名) − 实际名次   // 正=超预期(运气好), 负=不及预期
dev = clamp( dev×0.85 + clamp(delta×0.3, −0.75, +0.75) + rand(−1.2,+1.2) + bonus , −8, +8 )
```

| 事件 | bonus |
|---|---|
| 联赛冠军 | +1.5 |
| 国内杯赛冠军 | +0.8 |
| 洲际杯冠军 | +2.0 |
| 升级 | +1.0 |
| 降级 | −1.0 |

- **表现修正衡量"运气"**：预期名次按含 dev 的自洽强度在本联赛内排名。球队持续超预期时，自身强度上升→预期名次也随之提高→修正自我收敛，不会出现"爆冷一次就被钉在 dev 上限"的棘轮；长期不振作则被下限兜住。
- 防失控机制：`×0.85` 均值回归（优势半衰期约 4 季）+ 上下限 ±8。夺冠加成让冠军保持小幅优势后自然回落，联赛强队轮换。球队 `rep` 字段不随 dev 变动。

## 二、联赛引擎 `_lgSeason` / `_lgAll`

- `_lgTeams(lgId)`：`DATA.TEAMS` 按 `ap(t)===lgId` 过滤（升降级覆盖自动生效）。
- `_lgSeason(lgId)`：主客双循环（circle 法排程，用 `ad()` 打洗保证种子可复现），每场 `_matchSim(strH, strA)`；返回按 积分→净胜球→进球→id 排序的完整榜 `[{id,name,w,d,l,gf,ga,pts}]`。
- `_lgAll()`：一次跑全部 18 个联赛（约 6500 场/季），结果存 `a2.lastTables = {lgId: [teamId...]}`（**只保留最近一季**的最终名次数组，覆盖更新，控存档体积）。
- 可玩性定位：联赛整季后台结算出榜，玩家只看结果；大场仍只有德比/升级附加赛/保级战/洲赛决赛等既有节点。
- `b2()` §9b 统计聚合块整体替换：玩家行 → `bz.leaguePos/W/D/L/GF/GA/Pts`（字段形状不变，game.js 渲染零改动）。
- 球员个人出场/进球/助攻沿用现有统计公式，进球仍受真实球队 GF 上限约束；球员强度加成注入所在队的 `_matchSim` 强度。

### 5.2 赛制

- 瑞士轮联赛阶段（36 队 / 24 队）：按强度分 4 档（每档 9/6 队），每队与每档抽 2 个不同对手（主客各 1），共 8/6 场；同联赛球队回避；主客配平用启发式（允许个别队 5 主 3 客）。36 队制：前 8 直进 16 强、9–24 名打两回合附加赛；ACLE（24 队）：前 8 直进 16 强、9–24 附加赛。
- 淘汰赛：两回合主客（`_tieSim` = 两场 `_matchSim` 求和 + 平局点球），决赛单场中立地。
- 世俱杯：改为 32 队单场淘汰（每 4 年，沿用现有触发），参赛 = 近 4 届欧冠冠军（去重，历史不足时按 `_teamAbs` 强度补足）+ 18 联赛冠军 + 高强度补足。

### 5.3 时序

资格基于**上赛季**最终榜（`lastTables`/`lastCups`，现实规则）；首个赛季无历史时按 `_teamAbs` 强度排序补位。玩家队从资格赛/联赛阶段一路产出 `cupRuns`（沿用现有 `{comp, rounds[{round,opp,oppId,won,score}]}` 形状），进决赛保留现有可操作大场钩子。

## 九、比赛模拟 v2 校准（2026-09-05）

### 9.1 新模型（`_matchSim(aStr,bStr,gl,neu)`，全赛事统一）

旧的 `λ=1.35×(1±sd×0.85), sd=(a−b)/50` 独立双 Poisson 有三个结构性问题：主场优势随实力差缩放（均势对局反而没有主客场差，与现实相反）；实力→进球映射线性且过缓（冠军只有 73 分、垫底 32 分，spread 被压缩）；独立 Poisson 低估平局。

新模型（参数存于 `_msCfg`，由 `tools/calib_fit.py` 按现实拟合）：

- **份额模型**：总进球 `tot=2×base×gl`，主队份额 `share=home+k·sd+k2·sd·|sd|`，`sd=(aStr−bStr)/scale`；`base=1.40, scale=22, k=0.40, k2=0.16, home=0.57`。k2 二次项在极端分差时给弱队份额缓冲（保级区不被过度碾压）、给强队额外增强（冠军爬得上 90 分）。
- **主客场**：`home=0.57` 是恒定主场进球份额基准（现实主客进球约 55/45 分），`neu=true` 时基准 0.5（中立场地）。
- **平局修正**：净胜≤1 的比分按 `_msPd(gl)` 概率转为平局（低节奏联赛平局更多）：`pd+(1−gl)×0.18`。
- **风格随球队带入**：`_glOf(lgA,lgB)=√(styleA×styleB)`——国内杯赛用本联赛风格，洲际/世俱杯用双方联赛风格的几何平均，国家队固定 1.0。

### 9.3 加时与点球建模

- `_etSim`：加时 = 1/3 场时长的进球环境（同份额模型），仍平进点球。
- `_koSim`：90 分钟→加时→点球的单场淘汰结果（`{hg,ag,et,pk,won}`），应用于国内杯赛（`_cupBracket`，决赛中立场）、洲际决赛（中立场）、超级杯（中立）、升级附加赛决赛（中立）、国家队淘汰赛（全中立场）。
- `_tieSim`（两回合）：汇总平局→次回合加时→点球，`aggA/aggB` 含加时比分。
- 世界杯/亚洲杯小组与淘汰赛中立场化（`_simGroup4`/`knockoutStage` 传 `neu`），预选赛与友谊赛保留主客场。

## 十、球员数据统一 + 显示层修复（2026-09-05 第二轮）

### 10.1 球员数据归属统一（比分驱动）

此前球员数据三套路径各自为政：联赛「按出场独立生成 → 被球队总进球钳制」、国家队「每场独立伯努利概率（且 `_oppStr` 误用对手进球数当强度，大胜反而压制主角数据）」、大赛叙事独立一套。现统一为**从真实比分逐场归属**：

- `_pMatchContrib(tg,og,oppStr,ownStr,grp,boost)`：对本队每个进球，按位置份额（前锋 ~34%、中场 ~20%，助攻中场 ~20%）+ OVR 系数 + 对手相对强度差，伯努利分配进球/助攻；永不越过真实比分。
- `_pSeasonCollect/_pSeasonContrib`：归属池 = 当季全部真实比赛（联赛 lgFx + 国内杯赛 cupFx 签表 + 洲际瑞士轮与淘汰轮，两回合按总比分拆两场近似），从中抽 apps 场逐场归属——杯赛进球从此计入赛季总数据，apps 与可归属场次数一致。
- 国家队：同 `_pMatchContrib`，对手强度用 `_natStrOf`（NATS.s 缓存），中国队基准 60；门将零封改为由真实比分判定（og=0）。
- `_runWorld` 提前到赛季数据块之前，保证归属时 lgFx/杯赛签表已生成。

实测：ST 巅峰季 10-20 球（占球队 12-29%）、国家队 16 场 3-4 球，量级与现实一致。
