- 115 处静态 "NN% A / NN% B" hint 转 `g()` 动态；boot_deal 补转动态。

### 3. 队长机制
| 位置 | 改动 |
|------|------|
| `aA()` 视图 | 新增 `'teamId'`、`'isCaptain'`（`_captain===teamId`）、`'capDone'`（已接任俱乐部队长的俱乐部数组；`clubRep` 原有） |
| `aF()` 效果键 | `captain`：置 `_captain=teamId` 并记入 capDone；`capDecline`：只记入 capDone（拒绝后同俱乐部不再追问）；`ntCaptain`：置 `_ntCaptain` |
| `bk()` 每赛季 | 满足条件时直接把队长事件推入 `forceQ`（跳过随机池权重与 eventChance 门，当季即触发） |
| `bj()` 青训毕业 | 选「留在青训」设 `_gradCd=2`（再练 2 年，期间照常出青训事件，期满才再报价毕业；21 岁兜底淘汰不变） |

### 4. 队长触发门槛（forceQ 校验）
- **俱乐部队长**：有队 + 该队未接任过（capDone 不含当前队）+ `seasonsAtClub>=2` + `roleRank>=3`（主力/核心；rank：bench0/sub1/rot2/starter3/star4）+ **`ovr >= 50 + 4×clubRep`**（rep 0~3 → 门槛 50~62）+ `aB(age)==="prime"`（21~32 岁）→ 推 `captain`（非门将）或 `gk_captain`（门将）。
- **国家队队长**：`caps>=25` 且 `ovr>=72` 且未触发过（usedEvents 无 nat_captain 且无 _ntCaptain）→ 推 `nat_captain`。
