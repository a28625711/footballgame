## 2. 提高杯赛（欧冠/亚洲杯/世界杯/金球奖）相关度

**现状**（`sim.deob.js`）：
- **世界杯**（line 341-344）：4 年一届（`seasons.length%4===1` 判定）；普通档：`aM()["wcq"]` 概率出线 → `aP()` 按 ovr 生成成绩（冠军/亚军/stage）；cheat 档 ovr≥85 必冠
- **亚洲杯**（line 345-347）：4 年一届（`%4===3`）；cheat 档 ovr≥74 必冠
- **金球奖**（line 348-362）：cheat 档要求 rep≥4 且 ovr≥85；**普通档「无奖杯不参评」**，有杯时概率 `(0.06+0.24*aL())×(1+0.3×当年奖杯数)`
- **欧冠**（cont，line 317-324）：rep≥3 联赛才有概率；基础概率表 `TROPHIES.cont.p=[0,0,0,0.004,0.07,0.18]`
- **传奇加成**（`newState` cK）：开局固定 ovr/talent，**与杯赛成就完全无关**

**相关度偏低的表现**：
1. 传奇/天赋加成是死的，夺冠后无任何额外成长回馈
2. 世界杯权重固定，夺冠后除了奖杯/称号外没有实际数值奖励
3. 金球奖「无杯不评」，世界杯冠军赛季若俱乐部无杯仍可能不评
4. 欧冠/世界杯对 fame、身价、后续成长影响有限

**候选方案（需确认选哪些）**：
- A. **夺冠回馈**：世界杯/亚洲杯/欧冠/金球奖冠军赛季 → 永久 ovr 上限提升 或 talent 加成（例如世界杯冠军 talent+0.03）
- B. **传奇联动**：开局传奇球员 + 赢重大杯赛 → 额外成长加成（把传奇从「固定开局」变成「随成就成长」）
- C. **世界杯权重提高**：出线概率上调、世界杯表现→fame/身价/后续成长影响加大
- D. **金球奖放宽**：世界杯冠军赛季必参评（有杯即评），提高获奖与世界杯/欧冠绑定

**文件**：`sim.deob.js`（b2/b5/国家队块）+ 可能 `data.deob.js` | **风险**：中（数值平衡）

## 3. 老将属性高却被不续约（已定位根源）

**现状**（`sim.deob.js` `bo()` line 556-584 + `ba()/bb()/bc()/bd()` line 400-408）：
- 季末 `doPeriod`（line 494-498）：合同到期（`contractLeft<=0`）或 lowSpell 满 → 进 `bo()` 转会/续约流程
- `bo()` 决定能否留下（canStay，line 568）：
  ```js
  bE = bc(当前队)-5 >= bd(当前队)
  ```
- `bc(队) = 48 + 7.5×rep`（球队预算，rep5=85.5 封顶）
- `bd(队) = ovr + min(10, 0.08×fame) + min(12, 0.8×trophies数) - bb(age) + max(0,3-rep)×bb(age)×0.12`
- `bb(age)`：≤29=0；≤33=2×(age-29)；>33=8+4.5×(age-33)

**问题根源**：`bd`（球员身价）里 **ovr/fame/trophies 无上限**，而球队预算 `bc` 有上限（85.5）。只要 `ovr+荣誉加成 > 43+7.5×rep+bb(age)`，球员身价就超预算 → 无论年龄都被放走。例如 rep4 队上限仅 `73+bb`，ovr 80+ 的球员几乎必被不续约（换到哪个强队都一样）。年龄衰减在 bd 里是**减项**（老将反而更容易满足），所以这不是「年龄」问题，是「属性/荣誉过高」问题。

**候选方案（需确认）**：
- A. `bd` 中 ovr 加成封顶（如 ovr 部分封顶到 80，超出打折）
- B. 提高 canStay 阈值（`bc-5` → `bc+5` 之类）
- C. 忠诚因子：`seasonsAtClub≥3` 时放宽续约
- D. 老将保底：age≥32 且 ovr≥75 时必然给续约机会（解决用户观察到的「年纪大被赶走」）

**文件**：`sim.deob.js`（bd/bc/bo）| **风险**：低~中（影响转会难度，需平衡）
